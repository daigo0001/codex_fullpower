    実際の障害対応で残すこと
    途中から参加する人にも、今わかっていることが伝わるようにする。
    
      
      
        
    1. 影響を言葉にする
      誰が、どの操作で、いつから困っているかを共有します。担当と連絡窓口を決め、わかった事実から記録します。
      2. 
        
    2. 証拠をつなげる
      症状、ログ、メトリクス、変更履歴を時刻で見比べます。仮説を一つ立て、当たっていればどう観測されるかを確認します。
      3. 
        
    3. 影響を抑え、復旧を測る
      影響と戻し方を確認してから対応します。ユーザーの操作とエラー率の両方が戻ったか、一定時間観察します。
      4. 
        
    4. 再発防止の作業にする
      時系列、原因、対応と判断の根拠をまとめます。改善には担当、期限、完了条件を添えます。
