Header Guard

HTTP レスポンスヘッダーの防御設定を点検する。

ヘッダーの取得方法

対象ページの開発者ツールで「ネットワーク」を開いて再読み込みします。対象の通信を選択し、「ヘッダー」にあるレスポンスヘッダーをコピーしてください。
