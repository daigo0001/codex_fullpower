Codex Lab

アプリ一覧

インストール不要。ブラウザーで開いてすぐに使えます。

リリース管理

GitHub Release Lab

Issue と PR から本番までを追い、ブランチ戦略、公開判断、緊急修正と切り戻しを試せます。

公開の演習・Markdown 資料 アプリを開く

プロジェクト運営

Web開発 PL実践ラボ

問い合わせ管理の案件を担当し、顧客への確認から設計・見積・計画変更・公開判断まで試せます。

WBS・ガント・トラブル演習 アプリを開く

データベース設計

RDB Design Lab

備品貸出を題材に、テーブルと制約の決め方を学び、インデックスや同時更新の挙動を比較できます。

PostgreSQL の実行計画 アプリを開く

障害対応ラボ

Incident Lab

ログ・メトリクス・変更履歴から原因を絞り、対処と復旧確認までを模擬障害で練習できます。

復旧レポートを出力 アプリを開く

Azure ネットワーク

Azure Network Atlas

Azure の受信・送信、Private Endpoint、ハブ＆スポークの通信を図とステップで追えます。

VNet・サブネット・NSG・ルートを図解 アプリを開く

開発計画

Dev Blueprint

備品貸出アプリを例に、情報収集から設計・実装・リリースまでの手順と資料を学べます。

資料の記入例・WBS アプリを開く

暗号技術

Crypto Lab

パスワードハッシュ、共通鍵と公開鍵、ZIP の暗号化、電子署名を用途から学べます。

ハッシュ・暗号化のブラウザーデモ アプリを開く

Web 開発

MVC Flow

ASP.NET Core MVC のミドルウェア、ルーティング、フィルター、コントローラーを経て応答を返すまでを図で追えます。

実行順のステップ再生 アプリを開く

ネットワーク

Flow Atlas

DNS から HTTPS までを図と再生で追い、キャッシュや HTTP/3、DNS エラー時の違いを比較できます。

通信の図解・タイムライン アプリを開く

Web セキュリティ

Header Guard

HTTP レスポンスヘッダーを貼り付けて、CSP や HSTS などの防御設定と見直し箇所を確認できます。

入力はブラウザー内で処理 アプリを開く

天体観測

YOSORA

観測地と日時に合わせて星空を表示。天体の高度や観測しやすい時間帯を調べられます。

お気に入り・観測ノート アプリを開く
