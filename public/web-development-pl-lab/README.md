# Web開発 PL実践ラボ

社内問い合わせ管理システムの PL を担当し、顧客への確認、要件・設計、開発計画、変更管理とリリース判定を練習できます。最終演習では社内会議室予約システムの計画を自分で作成します。

## 開き方

- フォルダごと配布する場合は `index.html` をブラウザーで開きます。フォルダ内の `assets/` を同じ位置に置きます。
- ファイル1個で配布する場合は `standalone.html` を開きます。公開画面の「データ」からも「単体 HTML 版を保存」を選べます。
- iPhone で HTML の保存先のプレビューが演習を実行しない場合は、Safari の公開ページを使います。端末によるオフライン配布方法を確かめるときは、機内モードで HTML ファイルを開き、入力と出力を一度試してください。

演習にサーバー、アカウント、外部 API は不要です。参考資料の外部リンクを開くときはインターネット接続が必要です。JavaScript が無効でも章の目次と概要を読めます。

## 学習データ

回答と2案件の計画はブラウザーに保存します。ストレージが使えない場合はタブ内で作業できます。URL やブラウザーを変える場合は「データ」から JSON を保存し、新しい環境で復元します。復元は現在の作業内容を置き換えます。WBS から CSV、各章や最終演習から Markdown も保存できます。

WBS の初期値は案件名と日程・担当者です。完成例を読み込むと現在の案件の計画を置き換えるので、計画の比較用には先に JSON を保存します。実施日や工数は学習用の数値です。

## 配布と編集

`assets/js/` の教材データをブラウザーが直接読み込みます。`data/` の JSON と `templates/` の資料はコピーや参照向けです。教材実行時に `fetch()` で資料を取りに行く必要はありません。

開発者はリポジトリのルートで `npm run build:pl-lab` を実行すると、単体版 `standalone.html` と章構成を示す `data/learning-content.json` を再生成できます。Node.js が必要なのは再生成と開発時の検証です。
